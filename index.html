Cloudflare KV Database Integration Guide

This single page application is fully compatible with Cloudflare Pages Functions to fetch and write school details and pricing plans dynamically. Follow this simple 3-step setup to connect your Cloudflare KV Database:

1

Create a KV Namespace

Go to your Cloudflare Dashboard → Workers & Pages → KV Namespace, click Create a Namespace, and name it elimu_express_db.

2

Bind the KV namespace to Pages

Go to your Pages project in Cloudflare Pages dashboard → Settings → Functions → KV namespace bindings. Click Add binding. Set the Variable name to exactly MY_KV_NAMESPACE, SCHOOLS_KV, or ELIMU_DB and select the KV namespace you created (elimu_express_db).

3

Redeploy your project

Redeploy your pages project so the Pages Function script starts running. The connection status indicator at the top of the CMS dashboard will turn Green: Cloudflare KV Connected.

Note on Local Mode: If the database is not bound, the SPA continues to function seamlessly in offline/local storage mode, saving changes inside the current browser's LocalStorage. No server configuration or code modification is required!
